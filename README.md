# 🔥 Task Flow – Firebase Learning App

⚠️ This project is built **only for learning and practicing Firebase**.  
Main goal was to understand Firebase Authentication and Firestore with Flutter.

---

## 🎯 Purpose of This Project

- Learn Firebase Authentication  
- Learn Firestore database  
- Understand Stream in Flutter  
- Practice real-time data handling  
- Learn simple state management

---

## 🚀 Features

- ✅ User Signup  
- ✅ User Signin  
- ✅ Logout  
- ✅ Add tasks to Firestore  
- ✅ Update tasks  
- ✅ Delete tasks  
- ✅ Tasks load automatically using Stream  
- ✅ State managed using Stream  
- ✅ Splash screen to check login status using Shared Preferences

---

## 🛠 What I Used

- Flutter  
- Firebase Auth  
- Cloud Firestore  
- StreamBuilder  
- Shared Preferences  
- Dart

---

## 📱 How It Works

1. App opens Splash Screen  
2. Splash checks → user already login or not  
3. If login → go to Home  
4. Else → show Login / Signup  
5. Tasks load automatically using Stream  
6. User can add, edit, delete tasks
